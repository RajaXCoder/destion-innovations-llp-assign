E-Commerce Portal
Welcome to the E-Commerce Portal, a React-based application designed to help store owners manage invoices and products efficiently. This project provides a user-friendly interface for generating invoices, managing product details, and implementing filtering and searching functionalities.

Features
Invoice Management:

Generate and manage invoices.

View invoice details and calculate totals.

Product Management:

Add, edit, and delete products.

Filter products by store and search by name.

Authentication:

Login system for store owners.

Protected routes for authenticated users.

Responsive Design:

Works seamlessly on all devices (mobile, tablet, desktop).

Modern UI:

Clean and intuitive user interface built with Tailwind CSS.

Technologies Used
Frontend:

React: A JavaScript library for building user interfaces.

React Router: For routing and navigation.

Tailwind CSS: A utility-first CSS framework for styling.

React Icons: For adding icons to the UI.

Other Tools:

Vite: A fast build tool for modern web development.

js-cookie: For managing cookies in the browser.
